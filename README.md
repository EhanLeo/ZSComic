## 使用方法

将 `data` 上传到 `EhanLeo/ZSComic` 仓库根目录，覆盖原文件并提交。App 中继续使用：

`https://raw.githubusercontent.com/EhanLeo/ZSComic/main/data`

注意：App 更新图源时会保留本机数据库中已有的“首页推荐显示”开关。若曾经导入过旧版数据，更新后可在“我的 → 图源”中检查对应图源，将“是否在首页推荐显示”设为“是”；精品图源标记会随新版数据更新。
